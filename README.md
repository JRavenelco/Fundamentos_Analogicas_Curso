# Fundamentos de Sistemas Electrónicos Analógicos — Material del curso

Contenido educativo del curso (presentaciones Beamer, teoría, actividades, guías
de laboratorio y simulaciones LTspice). Ingeniería Aeroespacial · UNAM ENES Juriquilla.

## Estructura

- docs/presentations/ — presentaciones Beamer (PDF + .tex) por semana y actividad.
- docs/labs/ — guías de laboratorio, teoría y actividades.
- docs/classroom/ — programa, lineamientos, diagnóstico y presentación de inicio.
- docs/resources/ — recursos didácticos y enlaces validados.
- Simulaciones Ltspice/sim/ — netlists (.cir/.asc) reproducibles.

> Nota: este repositorio público contiene **solo** el material educativo del curso.
